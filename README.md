# 共有物（kyoyubutsu）

公開して困らないファイルを共有するための置き場所です。

## 置くもの

- 文章、メモ、手順書
- 設定ファイル、プログラム
- 小さな画像や図（目安：1ファイル数MBまで）

## 置かないもの

- 写真、動画、音楽
- 大きなファイル（50MBを超えるもの）、zip、インストール用のファイル
- 特定の人にだけ見せたいもの
- 他人が作ったもの（ダウンロードした画像・音楽、市販の資料など）
- 個人情報（名前、住所、連絡先、パスワード、鍵など）

## 載せる前の確認

このリポジトリは公開されていて、**一度載せたものは削除しても過去の記録から取り出せます**。載せる前に、次の点を確認してください。

- [ ] 写真や画像に、撮影場所（位置情報）などが入っていないか
- [ ] Word・Excel・PDF の作成者欄に、名前や会社名が入っていないか
- [ ] スクリーンショットに、通知・タブ・ファイル名など余計なものが映っていないか
- [ ] 誰に見られても困らない内容か

## フォルダ分け

ファイルが増えてきたら、種類ごとにフォルダを分けます（例：`docs/`、`images/`、`config/`）。

## ライセンス

このリポジトリのファイルは [CC0 1.0](LICENSE)（パブリックドメイン）として公開しています。誰でも、許可を取らず、作者名を書かずに、商用も含めて自由に使えます。

- 一度 CC0 で公開したものは、あとから取り消せません。
- 他人が作ったものは CC0 にできないため、このリポジトリには置きません。
